```go
    for _, 物品 := range 单角商店物品表 {      // 这一页把所有物品都扫一遍
        数量<=0 → continue
        识别(物品.名称) → 没找到 continue；找到 → 点击 + 本页买到=true
        加1 补数量 → 读 购买数量 → 对上点 确认 / 对不上点关闭
    }
    if !本页买到 { break }              // 这页啥都没买到 → 不翻了
    if 页 < m.次数 && 可滑("单角商店") { RandomSwipe(...) }   // 扫完才翻页
}
```
- 物品购买逻辑（加1/读购买数量/确认/关闭/回退）原样搬进内层，一个都没少。
- 收尾（点【单角购买】→点【回退】）在所有页循环结束后，位置不变。
