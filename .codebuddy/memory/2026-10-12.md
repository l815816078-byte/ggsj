## 挂机中 打怪超时（最终版）
plugin/挂机中.go：用 `ctx.Global["上次打怪时间"]` 记录时间戳（任务级 ctx 共用，每个任务 NewContext 一次 → 新任务自动从 0 计）。
- 没找到【自动攻击开启中】→ `delete` 打怪计时 + `return "no"`（走自动攻击；这段时间不算，回来重新从 0 计）。
- 找到【自动攻击开启中】后：`now := time.Now()`；只要检测到【怪物】(预设 535,69,550,83) 就刷新 `上次打怪时间=now`；首次进入初始化。
- `now - 上次打怪 > 100s`（内联固定）→ `return "#done"`（引擎 engine.go:272 直接 Success=true 结束整个任务，无需加 JSON 步骤）。
- "不算的时间"两段，跑完都把耗时 `+=` 回打怪时间：① sleep(10~100秒) ② 子任务(领取邮件等)。
- 关键：任务级所有步骤共用同一 ctx → 用 ctx.Global 跨步骤存；ctx.Data 每步新建不可用。插件返回 "#done" 或步骤名，引擎都支持（engine.go:272 / 287）。
