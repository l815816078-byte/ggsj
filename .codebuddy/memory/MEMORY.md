# ggsj 项目长期记忆（play 自动化脚本，Go）

## 一、硬约束（用户多次纠正，最高优先级）
1. **未经允许不准加新东西**（变量/常量/函数/字段/判断/配置/日志…）。让修就只修。"项目规则 > 我的判断"。
2. **一次性/单处使用的坐标、常量、颜色、阈值一律内联数字**，禁抽 `var/const`（≥2 处复用才抽）。
3. **不新增 md 里没有的方法/封装**："识别到就点它"统一 `查找点击延时`（老引擎 plugin/wait.go 已废弃）。
4. **循环手写 `deadline := time.Now().Add(...)` + `for ...Before(deadline)` + `if 已停止()`**，不编"最大轮数"常量。
5. **不动用户的嵌套循环结构**（`for A { for B {} }` 层级/顺序/归属保持原样）。
6. **只改用户点名的那一项**，不顺带改旁边字段（"加戏"= 挨骂）。
7. **识别日志里的 `sim:1.000` 不算用户指定阈值**：只有用户明确要求配阈值时才套 "1/1.000 → 0.95"。
8. **配置集中**：识别数据 → `点库.go`；业务参数（区域/偏移/滑动/表/常量）→ `业务配置.go`。任务 .go 只留流程逻辑。
9. **新增/移动包级变量前先 search_content 搜重名**。
10. **中文标识符不导出 → 所有 .go 同目录同包**（`package mian`）。
11. 工具坑：PowerShell 内联 `$变量` 会被吃 → 写 `.ps1` 再 `-File`；`go run` 本机被权限拦。
12. **输出坐标时只给"能直接复制的裸数字"**（`900,182,963,244` 一行一条），不要包 `{}/注释/说明`。

## 四、滑动表（2026-10-17 定稿）
- `业务配置.go` 就**一张** `滑动表 map[string]滑动项`，字段顺序：`前置验证 string` + 起点X/Y、终点X/Y、时长、滑后延时、次数。

```go
m := 滑动表["键"]

```
- 表内**每条后面不写 `//` 注释**，只留分组空行和表头上方说明。

## 七、ClickAdaptive（`mian/基础.go`）
```go
func ClickAdaptive(超时秒, 间隔, 重试次数 int, isDone func(name string), btns ...Btn) bool
```
- 超时秒 = deadline；间隔 = 轮间歇 ms；重试次数 = **连续**几轮整轮空转才收工（中途中过清零）。
- 调用点：领取邮件/背包物品/画册/加护①②③/买药/封印解除(60,500,3)，多为 `(3,500,3)`。
- 语义：Stop 命中即停返回 true（不点击）；Done 只标记；SkipStreak 连续同位置拉黑；SkipIfRecog 命中他则跳过；ClickOffset 点击偏移。
- **Btn 构造函数 5 个**：`btn(名,opts...)` / `btnStop` / `btnNeedHit(名,pre,opts...)` / `btnMulti(名,次数,gapMin[,gapMax])` / `btnDelay(名,minMs,maxMs,opts...)`（透传给 RandomClickInAreaWithDelay 第 5 个数；连点时由 ClickGapMs 承担）。
- `btn` opts 按类型识别：4 个连续 int=区域、第 5 个=SkipStreak、第 6/7=ClickOffset；单独 1 个 int=SkipStreak；bool=Done；string=SkipIfRecog；[]string=NeedHit。
- **使用判据**：老脚本用 ClickAdaptive 就照抄，不自己判断。`扫弹窗(名单[,轮数])` = 扫一遍看有什么挡路的。

## 八、🔴 子任务入口结构 + "没这功能就结束"

## 九、同质列表一律「一次点完」
- 红点/装备/类型表 → `for _, 点 := range 识别多个(...) { 点它; 处理带出的东西 }`。用户："不要这样 直接点完啊 还出去干屁啊"。
- ★ `识别()` 返回 3 值：`if _, _, x := 识别("X"); x {`。
- 例外（探测型，每轮一个）：背包格子、落花商店、气运类型表、福利翻页、点位寻路。**判据**：下一步依赖当前屏幕探测 → 每轮一个；纯同质点击 → 一次点完。

## 十、子任务「状态 + 完成判据 + 退出」
①【退出】永远都在，绝不拿它当完成判据；② 完成判据 = "该处理的没了"；③ **没东西处理也要正常退出、也算完成**。
- 迭代型 `第几个 >= len(列表)`（=0 也成立）；面板型分类走完且锚点不在；次数型 `次数 >= 上限`。
- 不加"空几轮确认"；退出只留一处；进度状态跨轮保留（重置只在完成后调）。

## 十三、架构事实
- **新框架 = `mian/`**（原 `zt/`），同包。旧 `plugin/`、`assets/tasks/`、`assets/recogs.json`、`bot/`、`task/` 全废弃。`zt/` 残留副本勿改。
- **文件职责**：
  - `点库.go` = 识别数据（预设 struct + 特征表）
  - `业务配置.go` = 业务参数（弹窗名单/区域表/偏移表/滑动表/常量/任务最大执行秒/物品表/挂机参数表）
  - `基础.go` = 识别原语 + ClickAdaptive + Btn
  - `主流程.go` = 任务表（唯一配置点）+ 轮转 + HUD
  - `挂机.go` = 挂机模块 + 子任务调度（派生，不自己维护表）
  - 各任务 `.go` = 流程逻辑（不抽辅助方法）
- **主循环**：每轮调任务表当前任务的 `跑()`（环，指针前移=轮转）。卡死：`适配次数>=20` → 切下一个；超时：`任务最大执行秒[当前任务]` → 切下一个。轮间 `RandomSleep(1000,1500)`。
- **挂机**：`挂机跑()` 被 野外挂机/每日任务/落花战场/门派战斗 调 = "谁调它谁就是挂机"；`跑子任务()` 挂机期间跑子任务。判据：有动静（怪物/省电_金币，100 秒无动静→重跑）；场景（仅落花）。
- **挂机参数表**：`type 挂机参数 struct { 判据 func() bool; 场景 string; 跑子任务 bool; 时长秒 int }`，`挂机.go` 零硬编码。教训：布尔组合判据用 `func() bool` 闭包，别用多字符串字段。
- **基础原语**：`识别()`（单，返 3 值）/ `识别多个()`（多，需寻找个数>1）/ `查找点击延时()` / `扫弹窗()` / `持续找色()` / `是否存在()`。
- **HUD**：状态行 = 当前任务+当前状态；进度行 = (已运行/上限)。

## 十四、单角商店扫法定稿（办法1「全局一遍扫」）
```go
for { 扫一遍所有物品（数量<=0跳过、买过了跳过）;
	这遍买到→continue（系统回第一页、滑了=0）;
	没买到→滑了++、滑满 m.次数(6) 收尾;
	否则可滑("单角商店")就往下滑一页 }
```
规则：滑动只往一个方向（不回滑）；点掉物品后系统自动跳回第一页所以计数清零；没找到不重置继续累加。**落花商店保持「按页扫全表」不变**（两个商店结构不同）。
