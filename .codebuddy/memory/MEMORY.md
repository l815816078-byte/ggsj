# ggsj 项目长期记忆（play 自动化脚本，Go）

## 一、硬约束（用户多次纠正，最高优先级）
1. **未经允许不准加新东西**（新变量/常量/函数/字段/判断/配置/日志…）。让修就只修。"项目规则 > 我的判断"。
2. **一次性/单处使用的坐标、常量、颜色、阈值一律内联数字**，禁抽 `var/const`（≥2 处复用才抽）。
3. **不新增 md 里没有的方法/封装**："识别到就点它"统一 `查找点击延时`（老引擎 plugin/wait.go 已废弃）。
4. **循环手写 `deadline := time.Now().Add(...)` + `for ...Before(deadline)` + `if 已停止()`**，不编"最大轮数"常量。
5. **不动用户的嵌套循环结构**（`for A { for B {} }` 层级/顺序/归属保持原样）。
6. **只改用户点名的那一项**，不顺带改旁边字段；改预设只加那一项，已有字段原样保留。
7. **识别日志里的 `sim:1.000` 不算用户指定阈值**：只有用户明确要求配阈值时才套 "1/1.000 → 0.95"。
8. **配置一律集中到 `mian/点库.go`**（特征表/区域表/偏移表/滑动表/业务配置）。任务 .go 只留流程逻辑，滑动坐标也必须在滑动表。
9. **新增/移动包级变量前先 search_content 搜重名**。改造状态变量：搜旧名引用 → 区分「跨轮状态」（留包级）与「循环内临时进度」（必须局部）→ 删旧 var 连带删重置函数里的赋值。
10. **中文标识符不导出 → 所有 .go 必须同目录同包**（`package mian`），不能分子目录。
11. 工具坑：PowerShell 内联 `$变量` 会被吃 → 批量改写 `.ps1` 再 `-File` 执行；`go run` 本机被权限拦。

**关键判断口径**：
1. **菜单展开面板**（点主菜单滑出的功能列表）只遮 y≥87 的按钮区，**遮不到右上角 `主菜单列表`（1150,9,1264,62）**——多点找色部分匹配点仍命中；**全屏功能面板**（画册/道术等）才遮得到。两者判断不能混。
2. **「没这功能就完成」的判据**：`else if 存在("主菜单列表")`（菜单开着 = 主菜单按钮被压住，而主菜单列表还认得到）。**不要用 `!存在`**（菜单开着时它恒 true → 永远判不出 → 死循环，2026-10-18 实测）。
3. **完成赋值后必须打日志**：`core.LogWithTimef("[X] ✅ 完成（原因）")`。
4. **子任务冷却日志**：`[子任务] 【X】冷却 13732 秒（区间 5000~10000 随机）→ 下次 12:31:22 可跑`。
5. **Go 里不存在 `存在()`**，一律 **`是否存在()`**——我连犯两次，写完新代码必须 grep `[^是否]存在\(` 自检。

## 六、ClickAdaptive（`mian/基础.go`）
```go
func ClickAdaptive(超时秒, 间隔, 重试次数 int, isDone func(name string), btns ...Btn) bool
```
- 超时秒 = deadline 驱动；间隔 = 轮间歇 ms；重试次数 = **连续**几轮整轮空转（一个都没命中）才收工，中途中过就清零重数。
- 9 个调用点：领取邮件/背包物品/画册/加护①②③/买药/封印解除(60,500,3)，多为 `(3,500,3)`。
- 语义：Stop 命中即停返回 true（不点击）；Done 只标记；SkipStreak 连续同位置拉黑；SkipIfRecog 命中他则跳过本按钮；ClickOffset 点击偏移。
- **Btn 构造函数 5 个**（2026-10-18）：`btn(名,opts...)` 普通 / `btnStop(名,opts...)` 命中即停 / `btnNeedHit(名,pre,opts...)` 前置状态 / `btnMulti(名,次数,gapMin[,gapMax])` 连点（间隔走 ClickGapMs）/ **`btnDelay(名,minMs,maxMs,opts...)` 单击后额外延时**（maxMs 传 0 = 固定 minMs；透传给 RandomClickInAreaWithDelay，= `查找点击延时(名,区域...,延时)` 那第 5 个数；连点时由 ClickGapMs 承担，AfterClickMs 不生效）。
- `btn` 的 opts 按类型识别：4 个连续 int = 区域、第 5 个 int = SkipStreak、第 6/7 = ClickOffset；单独 1 个 int = SkipStreak；bool = Done；string = SkipIfRecog；[]string = NeedHit。
- **使用判据**：老脚本用 ClickAdaptive 就照抄用，不要自己判断该不该。`扫弹窗(名单[,轮数])` = 扫一遍看有什么挡路的。

## 七、🔴 子任务入口结构 + "没这功能就结束"（2026-10-17 更新）
```go
查找点击延时("主菜单")
查找点击延时("XXX")
if 是否存在("XXX列表") {
	<干活>
} else if !是否存在("主菜单列表") {
	// 菜单开着（主菜单列表被盖住）却开不了 XXX 面板 = 菜单里没有这功能
	XXX已完成 = true
}
```
- 面板开着：主菜单/XXX 都认不到（跳过）→ 门过 → 干活；卡在别的面板：门不过 → 点关闭自救。
- **"主菜单列表没人用"的旧结论已作废**：2026-10-17 起它是 4 个子任务（画册/领取成就/灵力修炼/加护）的"菜单开着"判据——菜单/面板一开它就就盖住，天然表示"有面板遮右上角"。
- 判据顺序原理：**必须让 XXX列表 先分流**（在→干活），else 分支天然知道"不在面板里"，才敢问主菜单列表。`!是否存在("主菜单列表")` **不能放点主菜单之前**（那时菜单开没开未知，没点开→按钮不可见→点不到→误结束，且可能反复）。
- **加护是提前 return 结构**：在 `if !存在("加护列表") { 点关闭; return }` 里、点关闭**前**插 `if !是否存在("主菜单列表") { 加护已完成 = true; return }`，其余原样。
- 残余风险（已知可接受）：画面停在**别的**面板时会误结束——本来也是死循环空转，误结束只是提前退出，下轮冷却（10~20 秒）回来。
- 相关：`退出` 与 `主菜单` 是右上角同一处、天然互斥；但**绝不能拿【退出】判完成/判不在面板**。
- 9 个子任务锚点：邮件列表/成就列表/灵力列表/气运列表/画册列表/成长列表/加护列表/背包列表/福利列表。

## 八、同质列表一律「一次点完」
- 红点/装备/类型表 → `for _, 点 := range 识别多个(...) { 点它; 处理带出的东西 }` 一次全点完。用户："不要这样 直接点完啊 还出去干屁啊"。
- ★ `识别()` 返回 3 值：`if _, _, x := 识别("X"); x {`。
- 例外（探测型，每轮一个）：背包格子、落花商店、气运类型表、福利翻页、点位寻路。**判据**：元素本身是重活或下一步依赖当前屏幕探测 → 每轮一个；纯同质点击 → 一次点完。
- 不可中断性是已知代价（用户知情），别拿这个改回分轮。

## 九、🔴 不要给用户描述的流程"加戏"
用户给的流程长什么样就写什么样，一个字不加。被骂"复杂"时往**删**的方向改，不是换语法糖（if→switch 换皮会被识破）。
- "先点再认"优于"先认再决定点不点"。
- 加戏清单（自查）：三层嵌套 if/else、switch 三段链、`在面板`/`在主界面` 自造变量、拿【退出】当判据、给主任务编"优先级链"理由。
- 🔴🔴 **滑动是业务动作，绝对不准删/不准改**（"滑动不能动啊"）。"一次跑完"= 去分轮状态变量，不等于删滑动。现有滑动：画册列表、福利天数、福利积分、每日列表、开面板(落花+每日)、落花商店、成长列表、门派面板、找地点、找主城、扫弹窗"省电模式"。

## 十、子任务「状态 + 完成判据 + 退出」规范
三条铁律：①【退出】永远都在，绝不能拿它当完成判据；② 完成判据 = "该处理的没了"；③ **没东西处理也要正常退出、也算完成**。
- 迭代型 `第几个 >= len(列表)`（=0 也成立）；面板型（背包）分类走完且 `识别("背包")` 不在；次数型 `次数 >= 上限`。
- 不加"空几轮/连续 N 轮确认"；退出只留一处；进度状态跨轮保留（超时/打断回来接着干，重置只在完成后调）。

## 十二、架构事实
- **新框架 = `mian/`**（原 `zt/`），23 个 .go 同包。旧 `plugin/`、`assets/tasks/`、`assets/recogs.json`、`bot/`、`task/` 全废弃。`zt/` 残留副本勿改。
- **主循环（`主流程.go`）**：每轮 `跑当前任务()` 调任务表当前任务的 `跑()`（环，指针前移=轮转）。卡死：`适配次数>=20` → 切下一个；超时：`任务最大执行秒[当前任务]` → 切下一个。轮间 `RandomSleep(1000,1500)`。
- **挂机（`挂机.go`）**：`挂机跑()` 被 野外挂机/每日任务/落花战场/门派战斗 调 = "谁调它谁就是挂机"；`跑子任务()` 挂机期间跑 9 个子任务（各带冷却，B 方案：并入任务表切换驱动）。两条判据：有动静（怪物/省电_金币，100 秒无动静→重跑）；场景（仅落花，100 秒不见→重跑）。
- **挂机参数表（点库 init 赋值）**：`type 挂机参数 struct { 判据 func() bool; 场景 string; 跑子任务 bool; 时长秒 int }`。`挂机.go` 零 `当前任务=="xxx"` 硬编码。教训：布尔组合判据不能用多字符串字段（"太傻逼了"）→ 用 `func() bool` 闭包。
- **基础原语**：`识别()`（单）/ `识别多个()`（多，需寻找个数>1）/ `查找点击延时()` / `扫弹窗()` / `持续找色()` / `是否存在()`。
- **HUD**：状态行 = 当前任务+当前状态；进度行 = (已运行/上限)。
