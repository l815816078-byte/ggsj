## 野外挂机：选地点改成每次都重新随机（用户："每次都要重新走一遍随机"）
- `mian/野外挂机.go`：删掉包级缓存 `已选地点`（var 块 + `野外挂机重置()` 里的清空），`野外挂机跑()` 阶段一改成：
```go
地点 := 野外挂机地点
if 地点 == "" {
	地点 = 选地点(野外地点列表, 读战力())
}
```
- 以前：随机一次存进 `已选地点`，只有 野外挂机重置()（切任务/重跑）才重选 → 去地图失败重来时一直是同一个地点。
- 现在：每轮重新随机（85000 档两个：老虎谷/山君丘陵，二选一）。
- 安全依据：`去地图()` 是**一次调用跑完整段**（内部局部循环，失败 return false 并 defer 点【回退】清场），不会跨轮残留 → 每轮换目标不会串。
- `选地点()` 本身的随机逻辑没动（门槛≤战力取最高 → 同门槛 `候选[rand.Intn]`；战力不满足任何档取最低档随机；读不到战力返回空）。

## 新增 btnDelay：Btn 支持"点击后延时"（用户："在加一个新的 点击之后 可以透传 点击后延时的 毫秒数"）
- `mian/基础.go` 三处：① `Btn` 加字段 `AfterClickMs [2]int`（单击后额外延时范围，全 0 = 用 core 默认）；② 新增构造 `func btnDelay(name string, minMs, maxMs int, opts ...any) Btn`（内部先走 `btn` 解析 opts 再覆盖延时；`maxMs<=0` → 固定 minMs）；③ ClickAdaptive 点击分支加一条 `else if btns[i].AfterClickMs[1] > 0` 透传两个延时参数。
