## 新增预设【单角商店列表】+ 单角商店切换后检测（用户："切换单角商店之后 需要检测 如果不在要 return"）
- `点库.go`（"封印解除列表"后）：多点找色首点 `272|118|#FEF5E0-0x101010` + 19 个偏移整串照抄、相似度 **0.9**（用户给的）、区域 `{{64, 14, 297, 128}}`（= 日志的 l,t,r,b，末尾 `1,1` 丢弃）。
- `封印解除.go` 的 `单角商店跑()` **开头**加门：`if !是否存在("单角商店列表") { 打日志; return }` —— 点类型切换（区域 234,89,292,107）后如果没切进单角商店，直接返回，不再往下扫物品/滑动。
- 注意：它只挡 `单角商店跑` 自己；`封印解除跑()` 的类型表循环照旧，单角商店返回后继续点【退出】置完成。
- 🔴🔴 **"轮转"= 回主循环，不是在方法里自己循环重试**（用户："大错特错 是反到 主流程去 做弹窗在回来 那种"——我先在 `单角商店跑()` 里加了 for 重试 3 次被骂）。
  定稿（就是最初那版，别再改）：
```go
// 切到单角商店后先检测在不在；不在 → 本轮到此返回（回主循环）：
// 主循环扫完弹窗后下一轮会重新走整条链（主菜单 → 封印解除 → 类型切换 → 单角商店），自然轮转
if !是否存在("单角商店列表") {
	core.LogWithTimef("[单角商店] 没检测到【单角商店列表】→ 本轮返回，下轮轮转重来")
	return
}
```
- **原理**：`return` 不等于放弃。主循环每轮 `跑当前任务()` 会重跑整个任务入口（含进门链和类型切换），业务之后还有 `扫弹窗(任务弹窗)` → 这就是"回到主流程做弹窗再回来"。
- **教训（通用）**：用户说"检测不到要轮转/往上面翻"时，**默认指的是主循环轮转 = 直接 return**，绝不要在函数内部手写 for 重试、也不要在内部回点入口按钮。真要"内部重试"用户会明说次数。
- 🔴🔴 **补（用户："大哥 主循环也要退出 然后返回 return 啊"）**：子方法 return 只退出它自己，**外层任务函数会继续往下走**（原来：单角商店没进去 → 外层照样点【退出】+ `封印已完成 = true` = 没干成活却算完成）。
  正解 = **让方法把结果传出去，外层也 return**：
  - `封印类型.方法` 字段类型 `func()` → **`func() bool`**（false = 没进到这个类型）
  - `解除()` → `func 解除() bool`（末尾 `return true`，它本来就"找没找到都不影响"）
  - `单角商店跑()` → `func 单角商店跑() bool`；只**开头那处**检测不到返回 **false**，其余（已停止 / 买不了回退 / 点不到单角购买 / 正常收尾）全返回 **true**
  - `封印解除跑()` 循环里：`if !类型.方法() { 打日志; return }` —— 不点【退出】、不置 `封印已完成` → 下轮主循环重走整条链
- **通用判据**：子方法是任务链的一环时，"没进去/没干成"要能被外层感知（返回值/标志位），否则外层会照常收尾并误置完成。

## 画册：内层 `for true` 加超时 60 秒 + 间隔 1 秒（用户："循环 加上超时60秒间隔一秒"）

```go

	if 已停止() { return }
	查找点击延时("红点", 139, 170, 1168, 633)
```

- **最终形态（用户自己改成合并版 ClickAdaptive，我补了漏掉的参数）**：

## 🔴 ClickAdaptive：前置未满足【不算命中】（用户："这种情况不可以算命中啊"）
现象：【返回】一直认到但前置（要先点过红点）没满足 → 日志刷"√ 命中 + 前置未满足 → 跳过" → `中过` 被置 true → 空转永远清零 → 拖到 60 秒超时才收工。
- 修法（`mian/基础.go`）：把 `中过 = true` 从"识别命中后"**挪到 NeedHit 判断之后**——前置未满足就 `continue`，不置 中过。
```go
x, y, ok := 识别(...)
if !ok { continue }
LogWithTimef("√ 命中...")
if len(btns[i].NeedHit) > 0 && !hitAnyOf(hitNames, btns[i].NeedHit) {
	LogWithTimef("前置未满足 → 跳过（不算命中）")
	continue
}
中过 = true   // ★ 只有确定要处理（会点下去）才算命中
```
- 现在：红点没了 → 返回认到但不算命中 → 空转+1 → 连续 3 轮空转收工（不用等 60 秒）。
- 其它走 `continue` 的分支（SkipIfRecog 命中他、SkipStreak 拉黑那轮）**没动**，仍按原逻辑算/不算，别顺带改。
